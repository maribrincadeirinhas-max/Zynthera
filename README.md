# Zynthera

O primeiro jogo criado por mim em pixel 2D, onde o jogador precisa derrotar o chefe da fase rebatendo seus projéteis.

---

## Sobre o Projeto

Este jogo foi desenvolvido utilizando a **Godot Engine 4.5**.

### Funcionalidades e Características
* **Mecânica Principal:** Bossfight
* **Estilo Visual:** Pixel art

---

## Como Jogar

### Pré-requisitos
Para rodar ou editar o projeto, você precisará da **Godot Engine** instalada:
* [Download da Godot Engine](https://godotengine.org)

### Executando o Jogo (Desenvolvimento)
1. Baixe ou clone este repositório:
   ```bash
   git clone https://github.com/maribrincadeirinhas-max/Zynthera.git
   ```
2. Abra a Godot Engine.
3. Clique em **Importar** (Import) e selecione o arquivo `project.godot` na pasta do projeto.
4. Clique em **Editar** (Edit) e aperte `F5` para rodar o jogo!
